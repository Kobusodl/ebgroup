## Web3Forms setup

Open `contact.html` and replace:

```html
YOUR_WEB3FORMS_ACCESS_KEY_HERE
```

with the real Web3Forms access key.

## GitHub Pages deployment

1. Create a GitHub repository.
2. Upload all files from this folder to the root of the repository.
3. Go to **Settings > Pages**.
4. Set source to **Deploy from a branch**.
5. Select `main` branch and `/root`.
6. Save and wait for the GitHub Pages link.
